# Discovery flashcards (quiz yourself)

## Warm-up

**Q:** What’s the first thing you do after the AE no-shows?  
**A:** Own the room — short agenda, permission to discover, confirm assumptions. Don’t apologize for 5 minutes.

**Q:** Who are the three stakeholders and their primary jobs-to-be-done?  
**A:** CTO = outcomes/risk/portfolio · VP Eng = delivery/architecture · VP DevEx = adoption/governance/tooling.

## Pain → product

**Q:** They say Copilot is “fine for boilerplate.” What do you demo?  
**A:** Multi-file Agent change with Rules + tests; contrast with single-caret Copilot.

**Q:** They say reviews are the bottleneck. What do you name?  
**A:** Bugbot automatic PR review, `cursor review`, Fix in Cursor / Fix in Web / Cloud Agent.

**Q:** They say JetBrains is half the org. What do you *not* do?  
**A:** Don’t claim everyone switches IDEs next week. Offer phased rollout + CLI/ACP path; win the VS Code majority + agent workflows first.

**Q:** Security asks if code trains models.  
**A:** Privacy Mode org-wide; no training by Cursor or providers; ZDR; trust.cursor.com / SOC 2 Type II.

**Q:** They ask for on-prem Cursor.  
**A:** Not offered today. Enterprise cloud controls + private connectivity patterns for source control. Don’t invent a product.

## Business

**Q:** How do you talk cost without a quote?  
**A:** Seat list ($40 Teams / Enterprise custom) vs fully loaded eng time; pooled usage + spend limits; pilot ROI design.

**Q:** What’s a clean close?  
**A:** Recap 3 pains → 3 proofs → propose pilot teams + security session + send one-pager tomorrow + name owners.
