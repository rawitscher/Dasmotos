## Practice loop (30–45 min)

1. Skim the cheatsheet once
2. Say the **opening** and **POV** out loud (playbook §2 and §4)
3. Cold-run discovery questions without looking
4. In Cursor, open `demo/northstar-orders` and run Arc A + Arc B prompts from the demo README
5. Drill three objections from `OBJECTION_DRILLS.md`
6. Deliver the close cold
